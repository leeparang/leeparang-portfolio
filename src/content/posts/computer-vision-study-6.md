#### **1. CNN이란?**

CNN(Convolutional Neural Network, 합성곱 신경망)은 이미지 속 중요한 모양과 패턴을 찾아 무엇이 있는지 판단하는 인공지능 신경망이다.

이미지에서 특징을 추출하고, 이를 조합하여 객체의 종류를 예측하는 기술이다.

**(1) CNN의 처리 과정**

- 특징 찾기: 이미지에서 선, 모서리, 눈, 귀 등의 특징 추출

- 특징 조합: 추출한 특징들을 합쳐 복잡한 형태 파악

- 분류하기: 추출한 특징을 바탕으로 이미지의 종류 판단

예시) 고양이 사진을 입력했을 때

사진 입력 &rarr; 귀와 눈 등의 특징 추출 &rarr; 특징 조합 &rarr; 고양이로 분류

&rarr; CNN은 이미지의 특징을 자동으로 추출하고 분석하여 최종 결과를 예측한다.

#### **2. 이미지와 픽셀(Pixel)**

컴퓨터는 이미지를 사람처럼 직접 인식하는 것이 아니라 숫자 데이터로 처리한다.

이미지는 수많은 픽셀(Pixel)로 구성되어 있으며, 각 픽셀에는 밝기나 색상을 나타내는 숫자가 저장되어 있다.

**(1) 픽셀이란?**

- 이미지를 구성하는 가장 작은 점

- 각 픽셀에는 밝기 또는 색상 정보가 저장됨.

- 여러 픽셀이 모여 하나의 이미지를 구성함.

**(2) 컴퓨터의 이미지 인식**

사람이 보는 이미지: 고양이 사진

컴퓨터가 보는 이미지: 숫자로 이루어진 배열

![Study image](/study-assets/computer-vision-study-6-1.png)

각 숫자는 픽셀의 밝기 정보를 나타낸다 &rarr; CNN은 이러한 숫자 데이터를 분석하여 이미지의 특징을 찾아낸다.

#### **3. CNN이 등장한 이유**

기존 이미지 분석 방식은 사람이 이미지에서 어떤 특징을 찾아야 하는지 직접 지정해야 했다.

그러나 이미지의 모양, 위치, 배경이 달라지면 동일한 객체를 인식하기 어려웠다.

**(1) 기존 방식의 한계**

- 사람이 이미지의 특징을 직접 설정해야 함.

- 이미지의 배경과 형태가 달라지면 인식이 어려움.

- 다양한 이미지에 적용하기 어려움.

**(2) CNN의 특징**

- 이미지에서 특징을 자동으로 추출

- 선, 모서리, 질감 등의 특징 학습

- 작은 특징을 조합하여 복잡한 형태 인식

&rarr; 사람이 특징을 일일이 지정하지 않아도 CNN이 학습을 통해 중요한 특징을 찾아낼 수 있다.

#### **4. CNN의 기본 구조**

CNN은 이미지에서 특징을 추출하는 부분과 추출한 특징을 이용하여 최종 결과를 판단하는 부분으로 구성된다.

**(1) 입력 이미지(Input Image)**

분석할 사진을 CNN에 입력하는 단계이다.

**(2) 합성곱층(Convolution Layer)**

필터를 이용하여 이미지의 선, 모서리, 형태 등의 특징을 추출한다.

**(3) 풀링층(Pooling Layer)**

특징 맵의 크기를 줄여 중요한 정보를 요약하고 계산량을 감소시킨다.

**(4) 완전연결층(Fully Connected Layer)**

추출한 특징들을 종합하여 이미지가 어떤 종류인지 최종적으로 판단한다.

**전체 처리 과정**

입력 이미지 &rarr; 합성곱층 &rarr; 풀링층 &rarr; 완전연결층 &rarr; 분류 결과

※ 실제 CNN에서는 여러 합성곱층과 풀링층을 반복하여 사용할 수 있으며, 완전연결층에 전달하기 전에 평탄화 과정을 거칠 수 있다.

#### **5. 가중치(Weight)**

가중치는 신경망이 계산할 때 각 정보가 얼마나 중요하게 반영될지를 결정하는 숫자이다.

**(1) 가중치의 역할**

- 가중치가 작을 때: 해당 특징의 영향이 작게 반영됨.

- 가중치가 클 때: 해당 특징의 영향이 크게 반영됨.

- 학습 과정에서 가중치를 조정하여 예측 성능을 개선함.

**(2) 가중치 학습**

CNN은 예측 결과와 실제 정답의 차이를 확인하고, 오차를 줄이기 위해 가중치를 조금씩 조정한다.

&rarr; 가중치는 CNN이 이미지의 특징을 학습하는 데 중요한 역할을 한다.

#### **6. 활성화 함수(Activation Function)**

활성화 함수는 신경망에서 계산된 값을 정해진 규칙에 따라 변환하고 다음 단계로 전달하는 역할을 한다.

**(1) 활성화 함수의 역할**

- 신경망에서 계산된 값에 규칙 적용

- 결과값을 변환하여 다음 계층으로 전달

- 신경망이 복잡한 특징을 학습하도록 도움

**(2) 처리 과정**

계산 결과 &rarr; 활성화 함수 &rarr; 규칙 적용 &rarr; 다음 계층

활성화 함수는 계산 결과를 확인하고 정해진 규칙에 따라 다음 단계로 전달하는 문지기와 비슷한 역할을 한다.

#### **7. 필터(Filter)와 커널(Kernel)**

필터는 이미지에서 특정 특징을 찾기 위해 사용되는 작은 숫자 배열이다.

커널(Kernel)이라고도 부르며, 이미지에서 선이나 모서리 등의 특징을 추출하는 데 사용된다.

**(1) 필터의 구조**

![Study image](/study-assets/computer-vision-study-6-2.png)

필터는 이미지 위를 이동하면서 각 영역의 픽셀값과 계산을 수행한다.

**(2) 필터가 추출하는 특징**

- 세로선

- 가로선

- 모서리

- 질감

- 특정 형태나 패턴

필터마다 잘 찾아내는 특징이 다를 수 있다.

&rarr; CNN은 다양한 필터를 이용하여 이미지의 중요한 특징을 찾아낸다.

#### **8. 합성곱(Convolution)**

합성곱은 필터를 이미지 위에서 조금씩 이동시키면서 숫자를 계산하는 과정이다.

이미지의 각 영역에 필터를 적용하여 특정 특징이 얼마나 강하게 나타나는지 계산한다.

**(1) 합성곱 처리 과정**

- 입력 이미지에 필터를 겹친다.

- 겹쳐진 영역의 숫자들을 계산한다.

- 계산 결과를 새로운 배열에 저장한다.

- 필터를 다음 위치로 이동한다.

- 모든 영역에 반복하여 적용한다.

**(2) 합성곱의 결과**

합성곱 연산을 수행하면 새로운 숫자 배열이 만들어지며, 이를 특징 맵(Feature Map)이라고 한다.

입력 이미지 &rarr; 필터 적용 &rarr; 합성곱 계산 &rarr; 특징 맵 생성

&rarr; 합성곱은 CNN에서 이미지의 특징을 추출하는 핵심 연산이다.

#### **9. 특징 맵(Feature Map)**

특징 맵은 합성곱 연산을 통해 이미지에서 추출한 특징을 숫자로 표현한 결과이다.

필터가 특정 특징을 얼마나 강하게 발견했는지 나타낸다.

**(1) 특징 맵의 역할**

![Study image](/study-assets/computer-vision-study-6-3.png)

- 이미지의 특징을 숫자로 표현

- 특정 특징이 나타나는 위치 확인

- 다음 계층에서 추가적인 특징 분석에 활용

**(2) 특징 맵 해석**

특징 맵에서 값이 크거나 밝게 표현되는 부분은 해당 필터가 찾는 특징이 강하게 나타나는 위치일 수 있다.

예시)

세로선을 찾는 필터를 사용하면 이미지에서 세로선이 강하게 나타나는 영역이 특징 맵에 강조될 수 있다.

&rarr; 특징 맵은 CNN이 이미지에서 찾아낸 특징을 나타내는 결과이다.

#### **10. 스트라이드(Stride)**

스트라이드는 합성곱 연산에서 필터가 한 번 이동할 때 움직이는 칸 수를 의미한다.

**(1) Stride = 1**

- 필터가 한 칸씩 이동

**(2) Stride = 2**

- 필터가 두 칸씩 이동

#### **11. 패딩(Padding)**

패딩은 이미지의 가장자리에 새로운 값을 추가하는 기술이다.

주로 이미지의 테두리에 0을 추가하여 가장자리 정보의 손실과 출력 크기의 감소를 조절한다.

**(1) 패딩을 사용하는 이유**

- 이미지 가장자리의 정보 손실 감소

- 합성곱 연산으로 인한 크기 감소 조절

- 이미지의 테두리 부분도 충분히 분석할 수 있도록 도움

**(2) 패딩의 예시**

![Study image](/study-assets/computer-vision-study-6-4.png)

원본 이미지의 바깥쪽에 0으로 이루어진 테두리를 추가한 것이다.

&rarr; 패딩은 이미지의 가장자리 정보를 보존하고 특징 맵의 크기를 조절하는 역할을 한다.

#### **12. 풀링(Pooling)**

풀링은 특징 맵의 크기를 줄이면서 중요한 정보를 요약하는 과정이다.

합성곱 연산을 통해 만들어진 특징 맵에 적용하여 데이터의 양과 계산량을 줄인다.

**(1) 풀링의 목적**

- 특징 맵의 크기 축소

- 계산량 감소

- 중요한 특징 요약

- 이미지의 작은 위치 변화에 대한 민감도 감소에 도움

**(2) 풀링의 종류**

대표적인 풀링 방식에는 두 가지가 있다.

- 최대 풀링(Max Pooling): 영역에서 가장 큰 값 선택

- 평균 풀링(Average Pooling): 영역의 평균값 계산

#### **13. 최대 풀링(Max Pooling)**

최대 풀링은 일정한 영역에서 가장 큰 숫자 하나만 선택하는 방식이다.

![Study image](/study-assets/computer-vision-study-6-5.png)

**(1) 최대 풀링의 과정**

- 특징 맵을 작은 영역으로 나눈다.

- 각 영역에서 가장 큰 값을 찾는다.

- 최댓값만 남겨 새로운 특징 맵을 생성한다.

#### **14. 평균 풀링(Average Pooling)**

평균 풀링은 일정한 영역에 포함된 숫자들의 평균값을 계산하는 방식이다.

![Study image](/study-assets/computer-vision-study-6-6.png)

**(1) 평균 풀링의 과정**

- 특징 맵을 작은 영역으로 나눈다.

- 각 영역의 숫자를 모두 더한다.

- 숫자의 개수로 나누어 평균을 계산한다.

- 평균값을 새로운 특징 맵에 저장한다.

**(2) 최대 풀링과 평균 풀링 비교**

| 구분 | 최대 풀링 | 평균 풀링 |
| --- | --- | --- |
| 계산 방식 | 최댓값 선택 | 평균값 계산 |
| 특징 | 강한 특징 유지 | 전체적인 특징 요약 |
| 결과 | 영역의 최댓값 | 영역의 평균값 |

#### **15. 평탄화(Flatten)**

평탄화는 여러 행과 열로 이루어진 특징 맵을 하나의 긴 숫자 배열로 변환하는 과정이다.

CNN에서 추출한 특징을 완전연결층에 전달하기 위해 사용한다.

![Study image](/study-assets/computer-vision-study-6-7.png)

**(1) 평탄화의 특징**

- 다차원 특징 맵을 1차원 벡터로 변환

- 특징값을 한 줄로 정리

- 완전연결층에서 사용할 수 있도록 데이터 형태 변경

&rarr; 평탄화는 추출한 특징을 최종 분류 단계에 전달하기 위한 데이터 변환 과정이다.

#### **16. 완전연결층(Fully Connected Layer)**

완전연결층은 앞에서 추출한 특징들을 종합하여 이미지의 종류를 최종적으로 판단하는 계층이다.

![Study image](/study-assets/computer-vision-study-6-8.png)

**(1) 완전연결층의 역할**

- 추출된 특징들을 종합

- 특징 사이의 관계를 바탕으로 계산

- 최종적으로 이미지의 종류 예측

**(2) 분류 과정 예시**

고양이 이미지에서 다음과 같은 특징을 추출했다고 가정한다.

- 귀 특징

- 눈 특징

- 수염 특징

완전연결층은 이러한 특징 정보를 종합하여 고양이, 강아지, 새 등의 분류 결과를 예측한다.

&rarr; 완전연결층은 앞에서 추출된 특징을 바탕으로 최종 판단을 수행한다.

**(3) 단점**

1차원이기 때문에 공간 구조를 고려하지 못한다.

#### **17. 순전파(Forward Propagation)**

순전파는 입력 데이터가 신경망의 각 계층을 차례대로 통과하여 최종 예측 결과를 만드는 과정이다.

![Study image](/study-assets/computer-vision-study-6-9.png)

**(1) 순전파 과정**

- 이미지 입력

- 합성곱을 통한 특징 추출

- 풀링을 통한 특징 요약

- 평탄화를 통한 데이터 변환

- 최종 분류 결과 출력

입력 이미지 &rarr; 합성곱 &rarr; 풀링 &rarr; 평탄화 &rarr; 분류

**(2) 순전파 예시**

고양이 사진 입력 &rarr; 특징 분석 &rarr; 고양이일 확률 90% 예측

&rarr; 순전파는 입력 데이터를 이용하여 예측 결과를 생성하는 과정이다.

#### **18. 역전파(Backpropagation)**

역전파는 신경망의 예측 결과와 실제 정답의 차이를 이용하여 가중치를 조정하는 학습 과정이다.

![Study image](/study-assets/computer-vision-study-6-10.png)

**(1) 역전파 과정**

- 순전파를 통해 예측 결과 생성

- 예측 결과와 실제 정답 비교

- 오차 계산

- 오차를 줄이기 위한 가중치 조정

- 조정된 가중치로 다음 학습 진행

**(2) 역전파 예시**

- 입력 이미지: 고양이

- AI 예측: 강아지

- 실제 정답: 고양이

예측이 틀렸으므로 오차를 계산하고, 다음에는 더 정확하게 예측할 수 있도록 가중치를 조정한다.

**(3) 순전파와 역전파 비교**

| 구분 | 순전파 | 역전파 |
| --- | --- | --- |
| 목적 | 예측 결과 생성 | 오차를 줄이도록 학습 |
| 역할 | 입력 데이터를 이용한 계산 | 가중치 조정 |
| 특징 | 예측 수행 | 예측 성능 개선 |

&rarr; 순전파는 예측하는 과정이고, 역전파는 예측의 오차를 줄이기 위해 학습하는 과정이다.

#### **19. 에포크(Epoch)**

에포크는 전체 훈련 데이터를 한 번 학습하는 것을 의미한다.

CNN은 데이터를 반복적으로 학습하면서 가중치를 조정하고 성능을 개선한다.

![Study image](/study-assets/computer-vision-study-6-11.png)

**(1) 에포크의 개념**

1 Epoch = 전체 훈련 데이터를 한 번 학습

예시)

- 1 Epoch: 전체 학습 데이터 1회 학습

- 2 Epoch: 전체 학습 데이터 2회 학습

- 3 Epoch: 전체 학습 데이터 3회 학습

**(2) 반복 학습의 목적**

- 예측 오차 감소

- 가중치 조정

- 이미지 특징 학습

- 예측 성능 향상

반복 학습을 통해 성능이 개선될 수 있지만, 에포크를 늘린다고 항상 성능이 좋아지는 것은 아니다.

너무 많은 에포크를 한다면 과적합이 생길 수 있다.

#### **20. CNN의 장점**

CNN은 이미지에서 특징을 자동으로 추출하고, 물체의 위치가 조금 달라져도 특징을 인식하는 데 도움을 주는 구조를 가지고 있다.

**(1) 자동 특징 추출**

- 사람이 특징을 직접 설정할 필요가 줄어듦.

- 선, 모서리, 질감 등의 특징을 자동으로 학습

- 다양한 이미지의 특징을 분석할 수 있음.

**(2) 위치 변화에 비교적 강함**

- 이미지 속 객체의 위치가 조금 달라져도 특징 추출 가능

- 물체의 작은 위치 변화에 비교적 강인함.

&rarr; CNN은 이미지의 특징을 자동으로 학습할 수 있다는 장점이 있다.

#### **21. CNN의 한계**

CNN은 이미지 분석에 효과적이지만 학습 데이터와 계산 자원이 많이 필요할 수 있다.

**(1) 많은 학습 데이터 필요**

- 다양한 이미지 데이터가 필요함.

- 충분한 학습 데이터가 없으면 성능이 떨어질 수 있음.

**(2) 높은 계산량**

- 이미지 크기가 클수록 계산량 증가

- 신경망의 계층이 깊어질수록 연산량 증가

- 많은 계산 자원이 필요할 수 있음.

**(3) 과적합(Overfitting)**

과적합은 모델이 학습 데이터에 지나치게 맞춰져 새로운 데이터에 대한 예측 성능이 떨어지는 현상이다.

예시)

학습에 사용한 고양이 사진은 정확하게 분류하지만, 처음 보는 고양이 사진은 잘못 분류하는 경우

&rarr; CNN은 충분하고 다양한 데이터로 학습해야 하며, 과적합에 주의해야 한다.

#### **22. CNN의 활용 분야**

CNN은 이미지뿐만 아니라 영상, 음성, 문장 등의 데이터를 처리하는 분야에도 활용될 수 있다.

**(1) 이미지 및 영상 처리**

- 이미지 분류

- 영상 속 객체 탐지

- 콘텐츠 추천

**(2) 음성 처리**

- 음성 신호의 특징 추출

- 음성 명령 인식

**(3) 문장 및 텍스트 처리**

- 감성 분석

- 스팸 메일 분류

- 뉴스 기사 분류

&rarr; CNN은 다양한 데이터에서 특징을 추출하고 분석하는 데 활용될 수 있다.

#### **23. LeNet-5**

LeNet-5는 1998년에 소개된 대표적인 초기 CNN 모델로, 손글씨 숫자를 인식하는 데 사용되었다.

CNN의 초기 연구와 발전을 이해할 때 중요한 모델이다.

**(1) LeNet-5의 특징**

- 초기 CNN 모델 중 하나

- 손글씨 숫자 인식에 사용

- 합성곱과 풀링 등을 이용하여 이미지 특징 추출

**(2) LeNet-5의 처리 과정**

- 손글씨 숫자 이미지 입력

- 합성곱을 통해 특징 추출

- 풀링을 통해 특징 요약

- 추출한 특징을 이용하여 숫자 분류

예시)

손글씨 숫자 5 입력 &rarr; 특징 추출 &rarr; 특징 요약 &rarr; 숫자 5로 분류

&rarr; LeNet-5는 CNN을 활용하여 이미지 속 숫자를 인식하는 대표적인 초기 모델이다.

#### **24. CNN 전체 과정 정리**

CNN은 이미지에서 특징을 추출하고, 추출한 정보를 요약한 다음 최종적으로 정답을 예측하는 신경망이다.

**(1) 전체 처리 과정**

입력 이미지 &rarr; 필터 적용 &rarr; 합성곱 &rarr; 특징 맵 생성 &rarr; 풀링 &rarr; 평탄화 &rarr; 완전연결층 &rarr; 분류 결과

**(2) 핵심 개념**

| 개념 | 설명 |
| --- | --- |
| CNN | 이미지의 특징을 추출하고 분류하는 신경망 |
| 픽셀(Pixel) | 이미지를 구성하는 작은 점 |
| 가중치(Weight) | 정보가 계산에 반영되는 정도를 결정하는 값 |
| 활성화 함수 | 계산 결과를 정해진 규칙에 따라 변환 |
| 필터(Filter) | 이미지의 특정 특징을 찾는 숫자 배열 |
| 합성곱(Convolution) | 필터를 이동시키며 특징을 계산하는 연산 |
| 특징 맵(Feature Map) | 이미지에서 추출한 특징을 나타낸 결과 |
| 스트라이드(Stride) | 필터가 한 번 이동하는 칸 수 |
| 패딩(Padding) | 이미지 가장자리에 값을 추가하는 기술 |
| 풀링(Pooling) | 특징 맵의 크기를 줄여 정보를 요약하는 연산 |
| 최대 풀링 | 영역의 최댓값 선택 |
| 평균 풀링 | 영역의 평균값 계산 |
| 평탄화(Flatten) | 다차원 데이터를 1차원 배열로 변환 |
| 완전연결층 | 추출한 특징을 종합하여 최종 결과 판단 |
| 순전파 | 입력 데이터로 예측 결과를 생성하는 과정 |
| 역전파 | 예측 오차를 이용하여 가중치를 조정하는 과정 |
| 에포크(Epoch) | 전체 훈련 데이터를 한 번 학습하는 단위 |

**(3) 핵심 정리**

- 합성곱: 이미지의 특징 추출

- 풀링: 특징 맵의 크기를 줄여 정보 요약

- 평탄화: 특징 맵을 1차원으로 변환

- 완전연결층: 추출한 특징을 바탕으로 최종 분류

- 순전파: 예측 결과 생성

- 역전파: 오차를 줄이기 위한 가중치 조정

- 에포크: 전체 데이터 반복 학습

&rarr; CNN은 이미지의 작은 특징을 찾고, 이를 단계적으로 조합하여 최종 결과를 예측하는 인공지능 신경망이다.
