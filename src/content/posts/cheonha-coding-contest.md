## 天下第一 코딩大會

대회에서 맡은 역할과 문제 해결 과정, 결과를 기록합니다.

선린인터넷고등학교에 입학한 뒤 **처음으로 참가해 본 대회가 천하제일코딩대회였다.** 학교에 들어와 처음 나가는 코딩 대회였던 만큼 시작하기 전부터 긴장도 많이 됐지만, 한편으로는 내가 어느 정도까지 문제를 풀 수 있을지 궁금해서 설레기도 했다.

막상 대회가 시작되고 문제를 보니 생각했던 것보다 훨씬 어려웠다. 평소에 풀어보던 문제들과는 느낌도 달랐고, 제한된 시간 안에 문제를 이해하고 해결 방법까지 떠올려야 하다 보니 마음처럼 쉽게 풀리지 않았다. 결국 **많은 문제를 해결하지는 못했고 본선에도 진출하지 못해서 아쉬움이 남았다.**

그래도 이번 대회는 결과보다 **처음으로 실제 코딩 대회의 분위기를 경험해 봤다는 점에서 의미가 컸던 것 같다.** 직접 참가해 보니 내가 아직 부족한 부분이 무엇인지도 알 수 있었고, 앞으로 알고리즘 문제를 더 많이 풀면서 실력을 키워야겠다는 생각도 들었다. 첫 대회라 긴장했던 만큼 기억에도 오래 남을 것 같고, 이번 경험을 바탕으로 꾸준히 준비해서 **내년에는 더 좋은 성적을 내고 본선 진출에도 다시 한번 도전해 보고 싶다.**
