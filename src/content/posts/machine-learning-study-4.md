## 1. 이미지 분류란?

![이미지 분류](/study-assets/machine-learning-study-4-01.png)

이미지 분류(Image Classification)는 컴퓨터가 이미지를 분석하여 **미리 정해진 범주 중 하나로 구분하는 머신러닝 기술**이다.

사람은 사진을 보면 고양이, 자동차, 사람처럼 사진 속 대상을 쉽게 판단할 수 있지만, 컴퓨터는 이미지를 사람처럼 직접 보는 것이 아니라 이미지에 저장된 **픽셀의 숫자 값**을 이용해 이미지를 판단한다. 여러 이미지의 숫자 패턴과 정답을 학습하고 나서, 처음 보는 이미지가 들어왔을 때 어떤 종류에 해당하는지 예측한다.

**예)**

- 고양이 사진 → 고양이
- 비행기 사진 → 비행기

## 2. 이미지 분류 활용

이미지 분류 기술은 다양한 분야에서 활용된다.

- 사진 자동 분류
- 손글씨 숫자 인식
- 제품 불량 검사
- 의료 영상 분석
- 얼굴 인식
- 사물 인식

예를 들어 공장에서는 제품 사진을 분석하여 정상 제품과 불량 제품을 구분할 수 있다.

또한 손글씨 숫자 인식에서는 사람이 작성한 숫자 이미지를 분석하여 어떤 숫자인지 자동으로 판단할 수 있다.

## 3. 이미지 분류 과정

이미지 분류는 일반적으로 다음과 같은 과정을 거친다.

```text
이미지 입력 → 픽셀 숫자화 → 데이터 분리 → 모델 학습 → 예측 → 평가
```

**1. 이미지 입력**  
분류할 이미지 데이터를 컴퓨터에 입력한다. 컴퓨터는 입력된 이미지를 이후 숫자 데이터로 변환해 처리한다.

**2. 픽셀 숫자화**  
이미지를 구성하는 픽셀의 밝기나 색상 값을 숫자로 표현한다. 모델은 이 숫자들을 이용해 이미지의 특징을 확인한다.

**3. 데이터 분리**  
전체 데이터를 **학습 데이터**와 **테스트 데이터**로 나눈다. 학습 데이터는 모델 학습에, 테스트 데이터는 성능 확인에 사용한다.

**4. 모델 학습**  
학습 이미지와 정답을 이용해 모델이 이미지마다 나타나는 특징과 패턴을 학습한다.

**5. 예측**  
학습이 끝난 모델에 새로운 이미지를 입력하면, 학습한 특징을 바탕으로 어떤 종류인지 예측한다.

**6. 평가**  
모델의 예측 결과와 실제 정답을 비교하여 얼마나 정확하게 이미지를 분류했는지 확인한다.

## 4. 이미지 데이터

![이미지 데이터](/study-assets/machine-learning-study-4-02.png)

컴퓨터는 이미지를 우리가 보는 그림 그대로 이해하지 않는다.

이미지를 구성하고 있는 각각의 픽셀에 저장된 값을 **숫자 데이터**로 처리한다.

따라서 머신러닝에서 이미지 역시 숫자들의 집합인 하나의 데이터로 볼 수 있다.

이러한 숫자 패턴을 모델이 학습하면서 이미지 사이의 차이를 구분하게 된다.

## 5. 픽셀

![픽셀](/study-assets/machine-learning-study-4-03.jpg)

픽셀(pixel)은 **이미지를 구성하는 가장 작은 점**이다.

하나의 이미지에는 매우 많은 픽셀이 모여 있으며, 각각의 픽셀에는 색상이나 밝기를 나타내는 숫자가 저장되어 있다.

이미지를 확대했을 때 보이는 작은 사각형 하나하나가 픽셀이라고 생각할 수 있다.

픽셀 수가 많아질수록 이미지의 크기가 커지고 더욱 세밀한 모습을 표현할 수 있다.

## 6. 흑백 이미지

![흑백 이미지](/study-assets/machine-learning-study-4-04.png)

흑백 이미지는 각 픽셀의 **밝기 값**을 숫자로 저장한다.

밝은 부분과 어두운 부분이 서로 다른 숫자로 표현되기 때문에 컴퓨터는 이 값들의 차이를 이용하여 이미지의 모양을 구분할 수 있다.

예를 들어 손글씨 숫자 이미지에서는 숫자가 작성된 부분과 배경 부분의 밝기 값이 서로 다르다.

모델은 이러한 픽셀 값의 배치를 학습하여 숫자의 형태를 구분한다.

## 7. 컬러 이미지

![컬러 이미지](/study-assets/machine-learning-study-4-05.webp)

컬러 이미지는 일반적으로 **R, G, B** 값을 이용해 색을 표현한다.

- R : Red
- G : Green
- B : Blue

각 픽셀에 빨강, 초록, 파랑의 값이 저장되고 세 값이 조합되어 하나의 색을 만든다.

따라서 컬러 이미지는 흑백 이미지보다 한 픽셀이 가지고 있는 정보가 더 많다.

## 8. 이미지를 숫자로 표현하기

![이미지를 숫자로 표현하기](/study-assets/machine-learning-study-4-06.png)

머신러닝 모델은 그림을 그대로 계산할 수 없기 때문에 이미지를 숫자로 표현해야 한다.

이번에 사용하는 손글씨 숫자 이미지는 **8×8 크기**로 이루어져 있다.

8 × 8 = 64

따라서 이미지 한 장에는 총 **64개의 픽셀 값**이 존재한다.

이 8×8 형태의 픽셀 데이터를 64개의 숫자로 펼쳐서 머신러닝 모델에 입력할 수 있다.

즉, 모델은 우리가 보는 것처럼 숫자 모양 자체를 보는 것이 아니라 **64개의 숫자가 어떤 형태로 배치되어 있는지**를 비교한다.

## 9. 라벨

![이미지 라벨](/study-assets/machine-learning-study-4-07.png)

라벨(Label)은 각 데이터에 대한 **정답**이다.

예)

- 손글씨 숫자 0 이미지 → 라벨 0
- 손글씨 숫자 3 이미지 → 라벨 3
- 손글씨 숫자 7 이미지 → 라벨 7

모델은 이미지의 픽셀 값과 정답인 라벨을 함께 보면서 학습한다.

- 이미지의 픽셀 값 → 입력 데이터
- 이미지가 실제로 나타내는 숫자 → 라벨

## 10. 모델 학습

모델 학습은 이미지 데이터와 정답 라벨을 이용하여 **데이터 안에 존재하는 특징과 규칙을 찾는 과정**이다.

이미지 분류에서는 여러 이미지의 픽셀 값을 비교하면서 특정 숫자에서 자주 나타나는 패턴을 학습한다.

## 11. KNN

![KNN](/study-assets/machine-learning-study-4-08.png)

KNN(K-Nearest Neighbors)은 새로운 데이터가 들어왔을 때 **가장 가까운 K개의 학습 데이터를 찾아 분류하는 머신러닝 알고리즘**이다.

KNN은

> 서로 비슷한 데이터는 같은 종류일 가능성이 높다.

라는 아이디어를 사용한다.

새로운 손글씨 숫자 이미지가 입력되면 기존에 학습한 이미지 중 새로운 이미지와 가장 비슷한 데이터들을 찾는다.

그리고 주변 데이터의 정답을 확인하여 가장 많이 등장한 숫자를 새로운 이미지의 결과로 결정한다.

## 16. K의 의미

KNN에서 K는 새로운 데이터와 비교할 **가까운 데이터의 개수**를 의미한다.

예를 들어 K가 5라면 새로운 이미지와 가장 비슷한 이미지 5개를 찾는다.

만약 주변의 이미지가 다음과 같다면

```text
7, 7, 3, 7, 7
```

숫자 7이 가장 많이 등장하므로 새로운 이미지도 **7로 분류**한다.

K의 값에 따라 어떤 데이터를 주변 데이터로 사용할지가 달라지기 때문에 분류 결과에도 영향을 줄 수 있다.

## 17. KNN의 특징

KNN은 복잡한 학습식을 만드는 대신 기존에 존재하는 데이터와 새로운 데이터를 직접 비교하는 방식이다.

### 장점

- 동작 원리가 간단하다.
- 이해하기 쉽다.
- 분류 문제에 사용할 수 있다.
- 비슷한 데이터를 이용해 결과를 판단한다.

### 단점

- 데이터가 많아지면 비교해야 하는 데이터도 많아진다.
- 새로운 데이터를 예측할 때 시간이 오래 걸릴 수 있다.
- K의 값에 따라 결과가 달라질 수 있다.

## 18. 이미지 분류 정리

이미지 분류는 컴퓨터가 이미지의 특징을 학습하여 새로운 이미지를 특정 범주로 구분하는 기술이다.

컴퓨터는 이미지를 사람처럼 직접 이해하는 것이 아니라 이미지에 포함된 **픽셀의 숫자 값**을 이용한다.

이미지와 정답인 라벨을 함께 학습하면 모델은 데이터에 반복적으로 나타나는 특징과 패턴을 찾을 수 있다.

이번에 사용하는 digits 데이터에서는 하나의 손글씨 숫자 이미지를 8×8 크기의 픽셀 데이터로 표현하며, 총 64개의 숫자를 이용해 하나의 이미지를 나타낸다.

그리고 KNN을 이용하면 새로운 이미지와 기존 이미지 사이의 유사성을 비교하여 어떤 숫자인지 분류할 수 있다.

이번 내용을 통해 이미지도 결국 컴퓨터에서는 숫자로 표현되는 데이터이며, 머신러닝 모델이 이러한 숫자들의 패턴을 학습하여 이미지를 구분한다는 이미지 분류의 기본 원리를 이해할 수 있었다.
