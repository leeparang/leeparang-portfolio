## Supernova

웹 기반 채팅 서비스를 개발한 프로젝트입니다.

- 역할: Developer
- 분야: Web Development
- 사용 기술: python , flask , 롱폴링
- 내용: 
Supernova는 내가 직접 채팅 애플리케이션을 만들어보고 싶다는 생각에서 시작한 프로젝트다.

처음에는 디스코드처럼 여러 사람이 실시간으로 대화할 수 있는 프로그램을 만들어보고 싶었다. 단순히 메시지를 주고받는 기능만 있는 것이 아니라, 사용자들이 하나의 공간에 들어와서 대화하고 서로 소통할 수 있는 서비스를 직접 만들어보고 싶었다.

프로젝트를 생각하면서 가장 먼저 고민했던 것 중 하나는 이름이었다. 여러 이름을 생각하다가 **Supernova**라는 이름을 떠올렸다. 초신성이라는 단어가 주는 강렬한 느낌이 마음에 들었고, 내가 처음부터 직접 만들어가는 프로젝트에 잘 어울린다고 생각했다.

처음에는 단순히 "채팅 프로그램 하나 만들어보자" 정도의 생각이었지만, 프로젝트를 구체적으로 생각할수록 고민해야 할 것들이 생각보다 많았다.

사용자는 어떻게 가입할지, 친구나 다른 사용자는 어떻게 추가할지, 메시지는 어떤 방식으로 전달할지, 여러 사람이 동시에 대화할 수 있는 기능은 어떻게 만들지 등 단순히 화면을 만드는 것 외에도 생각해야 할 부분이 많았다.

특히 채팅 기능을 생각하면서 자연스럽게 실시간 통신에도 관심을 가지게 됐다. 사용자가 메시지를 보내면 상대방에게 바로 전달되기 위해서는 어떤 방식으로 서버와 통신해야 하는지 궁금했고, 이 과정에서 HTTP, 롱폴링, 소켓 같은 네트워크 기술에 대해서도 찾아보게 됐다.

프로젝트 하나를 만들기 위해서 단순히 프로그래밍 언어만 공부하면 되는 것이 아니라, 네트워크와 서버, 데이터 관리처럼 여러 기술이 함께 사용된다는 것도 알게 됐다.

Supernova는 처음부터 완벽하게 계획된 프로젝트는 아니었다. 오히려 **"이런 걸 만들어보고 싶다"는 생각에서 시작해서, 필요한 기능을 하나씩 생각하고 그 기능을 구현하기 위해 어떤 기술이 필요한지 찾아보는 과정**에 가까웠다.

하지만 이 프로젝트를 생각하고 준비하면서 내가 단순히 코드를 공부하는 것보다 직접 서비스를 만드는 것에 더 큰 흥미를 느낀다는 것을 알게 됐다.

하나의 기능을 만들기 위해 필요한 기술을 찾아보고, 문제가 생기면 원인을 생각하고, 조금씩 내가 생각했던 모습을 만들어가는 과정이 재미있었다.

Supernova는 나에게 단순한 채팅 앱 프로젝트가 아니었다.

내가 처음으로 **"이런 서비스를 직접 만들어보고 싶다"**고 구체적으로 생각했던 프로젝트였고, 개발을 공부하는 이유를 조금 더 명확하게 만들어준 프로젝트이기도 하다.

완성된 결과물도 중요하지만, 지금 다시 생각해 보면 이 프로젝트를 통해 가장 크게 얻은 것은 직접 무언가를 만들기 위해 고민했던 경험인 것 같다.

아이디어 하나에서 시작해서 이름을 정하고, 필요한 기능을 생각하고, 그 기능을 만들기 위해 어떤 기술을 공부해야 하는지 찾아봤던 과정 자체가 나에게는 의미 있었다.

Supernova는 그렇게 내가 개발이라는 분야를 단순히 공부하는 것에서 조금 더 나아가, **내가 생각한 것을 직접 만들어보고 싶다는 목표를 가지게 된 시작점 중 하나**로 기억하고 싶다.
